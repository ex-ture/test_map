## 主要パッケージ

以下の主要パッケージを使用しています。

| パッケージ | 用途 |
|---|---|
| google_maps_flutter | Google Maps表示 |
| geolocator | 現在位置取得 |
| shared_preferences | 端末内データ保存 |
| webview_flutter | Webページ表示 |
| url_launcher | 外部URL起動 |
| http | API通信 |

## 動作条件

本アプリでは以下の環境・機能を必要とします。

- iOS端末
- iOS 15.0以上
- インターネット接続
- 位置情報サービス

※インターネット接続は地図表示や店舗検索に使用します。  
※位置情報サービスは現在地取得機能で使用します。
